Subterranean Song Company

Live Demo: https://subterranean-song-company.netlify.app/

Overview

Responsive website showcasing Bill Meehan, a singer-songwriter and vinyl record collector. Features his biography, family background, and top albums with embedded Spotify tracks. 
Created as part of SheCodes Responsive Bootcamp and as a gift to highlight his musical passion.

Features

- Fully responsive layout for desktop, tablet, and mobile

- Biography

- Top three albums with Spotify embeds and external links

- Hover effects on album cards for interactivity

- Dynamic JavaScript for years of experience

Technologies Used

HTML | CSS (Grid & Flexbox) | JavaScript | Google Fonts | Spotify Embed API
